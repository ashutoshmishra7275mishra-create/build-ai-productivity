# 🚀 AI Productivity OS

An AI-powered productivity platform designed to help users organize their daily tasks, manage notes, plan schedules, and interact with an AI assistant from one place.

## ✨ Features

- 📊 **Dashboard** — View and organize your productivity activities.
- ✅ **Task Management** — Create and manage daily tasks.
- 📅 **Calendar** — Organize your schedule and important events.
- 📝 **Notes** — Keep your notes organized in one place.
- 🤖 **AI Assistant** — Interact with an assistant through a chat interface.
- 🔐 **Authentication** — Login and signup pages.
- ⚙️ **Settings** — Manage application preferences.

## 🛠️ Tech Stack

**Frontend**
- React
- Vite
- Tailwind CSS
- JavaScript

**Backend**
- Node.js
- Express.js
- Database and authentication components

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/ashutoshmishra7275mishra-create/build-ai-productivity.git
cd build-ai-productivity
```

### 2. Set up the backend

```bash
cd backend
npm install
```

Configure the required environment variables in a local `.env` file according to your backend configuration.

Start the backend using the script defined in `backend/package.json`.

### 3. Set up the frontend

Open another terminal:

```bash
cd frontend
npm install
npm run dev
```

Open the local URL displayed by Vite in your terminal.
